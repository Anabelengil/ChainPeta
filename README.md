# ChainPeta

ChainPeta is a decentralized, auto-scaling platform for real-time-processing of cryptocurrency transactions on a distributed Chain, leveraging PetaStore technology.

The key benefits of using ChainPeta include:

- ChainPeta is a decentralized, auto-scaling
- platform for real-time-processing of cryptocurrency
- transactions on a distributed Chain,

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/ChainPeta.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
